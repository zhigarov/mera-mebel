# МЕРА — корпусная мебель на заказ в Томске

Демо-версия сайта для согласования с заказчиком.

Сайт — обычный HTML/CSS/JS без сборки. Форма заявки работает только на хостинге с PHP
(`send.php` отправляет заявки в Telegram и MAX), поэтому в демо-версии на GitHub Pages
вместо отправки показывается сообщение с контактами.

Фото на первом экране и в блоке «О нас» — Unsplash (бесплатная лицензия Unsplash).
Фото в портфолио — работы компании.
